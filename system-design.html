Memory Systems
⚡ Working Memory
CampaignState TypedDict — live in LangGraph
All agent I/O slots, task plan, events list
store: in-process RAM · lifetime: one run
🎞️ Episodic Memory
Past campaign execution snapshots
Similarity search for few-shot context
extract_campaign_lessons() distils:
  best_tones · avoid_tones
  top_pillars · best_ctas · top_score
store: ChromaDB "episodes" · persisted
📚 Semantic Memory
Pre-seeded knowledge base (platform specs)
LinkedIn / Twitter ad rules, AIDA copywriting
Embedding similarity retrieval per agent
store: ChromaDB "knowledge" · seeded once
💬 Conversation History
Full message log per session (SQLite)
Rolling LLM summary (gpt-4o-mini)
Incremental: only new turns summarised
Coordinator injects summary + recent turns
store: SQLite conversations + conversation_summaries
🏷️ Entity Memory
Structured extraction from user brief
product · campaign_goal · target_audience
tone · platforms (upserted per run)
store: SQLite entities table
📜 Procedural Memory
Standard Operating Procedures (SOPs)
Campaign planning · content quality review
Ad copywriting · publishing workflow
store: ChromaDB "procedures" · seeded once
🔄 Learning Loop
Publisher → stores episode (score + tone + pillars + CTAs)
Coordinator → extract_campaign_lessons()
Next run: best_tones · avoid_tones injected
  into Strategist + Content Writer prompts
